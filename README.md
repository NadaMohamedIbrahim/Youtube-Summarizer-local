# 🎓 AI YouTube Tutor & Summarizer

A Streamlit web app that extracts YouTube transcripts and acts as a personalized AI tutor. Built with `llama-cpp-python`, LangChain, and FAISS vector databases.

## 🎬Features
* **📝 Smart Summaries:** Generates precise, bulleted summaries of long videos using Qwen 2.5 (1.5B).
* **📚 Study Pack & Quiz:** Automatically extracts key terms into flashcards and generates a multiple-choice quiz.
* **💬 Chat with Video (RAG):** Uses FAISS and LangChain to let you ask questions and chat directly with the video's context.
* **⚡ Fully Local & Private:** Runs entirely on your own hardware without sending data to external cloud APIs.
