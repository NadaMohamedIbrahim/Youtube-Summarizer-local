# Local YouTube Summarizer 🎬
A GPU-accelerated Streamlit web app that extracts and summarizes YouTube transcripts using Qwen 2.5 local AI.
This project is a privacy-first, fully local web application that extracts YouTube video transcripts and summarizes them using on-device AI. Built with Streamlit and llama-cpp-python, it leverages the Qwen 2.5 Instruct model with GPU acceleration to process videos quickly and accurately without relying on external cloud APIs.
